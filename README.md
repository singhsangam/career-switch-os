## Run locally

```bash
cd career-switch-os
npm install
npm run dev
```

## Phone + laptop sync (any location)

Progress is **not** tied to the deploy. App/code updates on refresh keep your status.

1. Follow **[HOSTING.md](./HOSTING.md)** (Supabase + Vercel, ~10 minutes once)
2. Copy your `RTD-****` sync code on one device
3. Paste it on the other → same journey worldwide

Until cloud keys are set, progress still saves in the current browser.
